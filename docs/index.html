🎓 VU EA Conversational AI

Vraagbaak voor de 1cijferHO-documentatie van VU Education Analytics. Kopieer hieronder één commando en de app installeert zichzelf en start op je eigen laptop.

1. Start de app

Open PowerShell (Windows-toets, typ “PowerShell”) en plak:

PowerShell
irm https://jorngithub.github.io/VU-EA-Conversational-AI/start-windows.ps1 | iex

Geen Python? Het script zegt precies wat je moet installeren (winget install -e --id Python.Python.3.12).

Open Terminal (Cmd+spatie, typ “Terminal”) en plak:

Terminal
curl -fsSL https://jorngithub.github.io/VU-EA-Conversational-AI/start.sh | bash

Geen Python 3.10+? Het script vertelt hoe je die installeert (brew install python).

Open een terminal en plak:

Terminal
curl -fsSL https://jorngithub.github.io/VU-EA-Conversational-AI/start.sh | bash

Op Debian/Ubuntu heb je python3-venv en git nodig: sudo apt install python3-venv git.

Deze pagina start zelf niets — dat kan een website niet. Ze geeft je het commando; de app draait daarna volledig op je eigen computer. Wil je eerst zien wat het script doet? Bekijk start.sh of start-windows.ps1.

2. Wat gebeurt er dan?

  1. Code ophalenDe repository wordt naar je thuismap gekopieerd, of bijgewerkt als je hem al hebt.
  2. Python-omgevingEen eigen virtual environment, zodat je systeem-Python ongemoeid blijft.
  3. Installeren en klaarzettenpython main.py installeert de dependencies, haalt de Ollama-modellen op en bouwt eenmalig de semantische index.
  4. App opentJe browser gaat naar http://localhost:8501. Stoppen doe je met Ctrl+C.

De eerste keer duurt het langer (modellen zijn enkele GB’s). Daarna start de app snel.

4. Liever dubbelklikken?

Download het startbestand voor jouw systeem, zet het op je bureaublad en dubbelklik het voortaan.

⬇ start-windows.bat ⬇ start-macos.command ⬇ start.sh (Linux)

Windows toont de eerste keer SmartScreen (“Meer informatie” → “Toch uitvoeren”). macOS vraagt de eerste keer om rechtermuisknop → Open. Op Linux maak je het bestand uitvoerbaar met chmod +x start.sh.

5. Werkt er iets niet?

“python wordt niet herkend” of “command not found”

Python staat niet in je PATH. Installeer Python opnieuw en vink op Windows “Add python.exe to PATH” aan. Daarna PowerShell of Terminal opnieuw openen.

Er opent geen browser

Kijk in de terminal: daar staat de URL (meestal http://localhost:8501). Klik die aan of plak hem in je browser.

Het LLM-antwoord blijft lang leeg

De eerste keer laadt het taalmodel; de app toont een teller. Duurt het daarna nog steeds lang, kies dan een kleiner model in de zijbalk (qwen3:4b of qwen3:1.7b) en meet met python main.py --benchmark-llm.

Ik wil geen Ollama installeren

Hoeft niet. De app beantwoordt vragen dan uit de lokale documentatie; alleen de LLM-formulering en de semantische zoeklaag zijn dan uit.

Poort 8501 is al bezet

Start met een andere poort: python -m streamlit run app_streamlit.py --server.port 8502.

De app draait lokaal: je vragen en de documentatie blijven op je eigen machine. Broncode en volledige uitleg staan in de GitHub-repository.
